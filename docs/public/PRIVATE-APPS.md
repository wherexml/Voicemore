# 不留历史的应用

设置 → 隐私 → 不留历史的应用。列表中的应用照常写入，但本次听写不保存历史文字和录音，也不观察修改、不产生词典候选。界面以 [mock/language-privacy.html](../../../mock/language-privacy.html) 为准；实现见 `internal/session/privacy.go`、`prefs_privacy.go`。

## 实现前失败路径

- 开始时在私密应用，结束前切到普通应用（或反过来）：只要任一端命中就整次私密，后续不能恢复为普通。
- 先写入历史再删除：崩溃或删除失败会留下正文、录音或统计；必须在目标确定后才落盘。
- 识别失败、整理失败、未写入、剪贴板回退、写入中取消：每条路径都要判断私密，不能因为没有写入目标就默认保存。
- 整理失败等待用户选择时：重试、写入原文、复制、关闭、Esc 都必须只结算一次，迟到结果不得写入。
- 修改观察已启动后应用被加入列表：不得提交词典候选或观察记录。
- 写入中取消与插入完成竞争：不能一边按取消保存、一边按私密丢弃。
- 练习、保留取消录音（keepCancelled）、自动发送编辑回写也是写入历史的路径。
- 已有历史不能被删除、改写或重新分类；重新转写/整理旧记录保持原样。
- Bundle ID 为空的应用不能误匹配；同名不同 Bundle ID 不能误匹配。
- 不改变云端或自定义识别路由，不改变写入、远程桌面与自动发送行为。

## 行为

- 配置 `privateApps[]`：`bundleId` 精确匹配、`appName` 仅显示；从正在运行的桌面应用添加，复用自动发送的标准选择器，已添加项不再出现在候选中。旧配置缺字段为空列表。
- 判定：录音开始时的前台应用，或实际写入目标（本地粘贴、远程客户端、剪贴板回退时的前台应用）任一在列表中即为私密；同时检查开始时与当前设置。标记具有粘性。
- 在 macOS 捕获实际目标后、任何写入或错误返回之前，通过 `OnTarget` 记住隐私判定，后续焦点变化不能撤销。
- 没有写入目标的结束（识别失败、无语音、整理失败后复制或关闭、写入中取消、写入报错）以结算时的前台应用补充判定。
- 记录在 `finish` 只在内存中组装；`persist` 在目标确定后一次性写入记录与录音，私密则直接丢弃。录音 PCM 只在内存中，不写临时文件。胶囊仍保留文字以便复制或重试，关闭后丢弃。
- 私密运行：粘贴前不启动修改观察；观察中途变为私密时不调用 `Dict.Propose`、不写观察说明。
- 取消：未定稿且开启保留取消时，私密则不保存；已定稿时改为“已取消”后结算；写入进行中则交给写入流程按实际目标结算。
- 首页/历史统计只来自已保存的记录，因此私密运行不计入。

## 原生验收

使用可丢弃的测试应用（如 TextEdit 与验收夹具），不要用真实聊天对象。

1. 设置添加 TextEdit，退出重开：列表保留；移除后重开不再显示。
2. 在 TextEdit 听写：文字写入；历史、统计、`history/` 中均无新记录和 WAV。
3. 在普通应用开始、切到 TextEdit 结束（及反向）：均不保存。
4. 开启修改观察，在 TextEdit 写入后修改专有名词：词典无新候选。
5. 整理服务不可达：分别选择重试、写入原文、复制、关闭；均不保存。剪贴板回退（焦点无输入框）同样不保存。
6. 写入中与录音中取消（开启保留取消）：私密不保存，普通应用按原规则保存。
7. 普通应用回归：记录、录音、观察与自动发送行为不变；旧记录数量与内容不变。

证据（历史目录前后哈希、截图、设置 JSON）保存到本地 `artifacts/language-privacy/`，不入库。
## 设置恢复保护

设置主文件损坏或丢失而备份仍存在时，旧备份可能缺少最新私密应用。应用会保留原件并停止启动听写；重复启动也不会自动接受旧隐私规则。须在本机核实并修复有效配置后重开。控制器与落盘路径同时保留保护，见[配置恢复与隐私验收](../../internal/config/README.md#状态持久化与恢复)。
