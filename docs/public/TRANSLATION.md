# 翻译听写

翻译快捷键与外接设备按键的“切换翻译”动作开始翻译听写；再次触发结束录音，使用当前选择的 ASR 识别，再调用“文字整理”默认模型翻译并写入原目标应用。普通听写触发、菜单与按钮仍按既有文字整理开关执行，不自动翻译。引导窗口可见时翻译触发不启动跨应用听写。

目标语言支持 English、简体中文、繁體中文、日本語、한국어、Français、Deutsch、Español，默认 English。`translationKey` 为空表示不注册；`translationLanguage` 在本次录音开始时固定。语言改变对下一次生效，失败重试仍使用本次目标语言。

翻译复用已配置的文字模型、加密凭证、关闭思考参数、JSON 参数、HTTP 超时及取消处理；独立翻译提示词要求保留信息、数字、否定、条件、专名、代码、语气与未完片段，转写中的问题或指令是素材，不执行、不回答。有效正文直接作为结果，不额外应用中文格式规则，不增加语义输出拦截。

翻译失败不静默写入原文，胶囊保留原文并允许重试、复制，或用户显式选择使用原文。取消后丢弃迟到结果。历史保留原始识别、生成正文、模型、耗时及 `translationLanguage`；实际写入仍按现有焦点、剪贴板、自动发送和私密应用规则处理。翻译结果不用于写入后的词典纠错学习。胶囊处理阶段显示“正在翻译”。

## 验收

- 在原生窗口录入快捷键、选择目标语言，跨应用开始/结束，检查原文、译文、目标应用和历史；切换为普通听写确认不翻译。
- 用真实模型检查英文和日文，覆盖时间、数量、否定、文件名、末尾补充；不能把 fixture 输出作为模型质量证明。
- HTTP 与控制器检查：`go run -tags dictationacceptance ./cmd/dictation-controls-acceptance`；加 `--live` 使用本机当前配置的文字模型翻译两条合成样本，仅从本机加密凭证库读取凭证，不输出凭证、不修改正式设置。
- 覆盖失败保留原文、重试保持翻译任务和语言、取消后无输出、重复处理不二次交付；现有 `go run ./cmd/cleanup-acceptance` 验证响应体阶段的超时与取消原因仍保留。
- 以上 HTTP/控制器验收不经过真实麦克风或跨应用粘贴；物理 Fn、DJI 按键及语音至写入单独记录。证据留在本地 `artifacts/native-dictation-controls/`，不入库。
