# DJI 接收器按钮

macOS 自动接管已验证的 `Wireless Mic Rx`（USB VID 11427 / PID 16401）的 Consumer Control 接口（Usage Page 12 / Usage 1）。连接键发出的 Volume Increment（233）按下后等待 350 毫秒：单击切换听写；同一设备在窗口内第二次按下取消单击，仅发送一次无修饰键的 Enter。与键盘“按住说话”设置独立。单击在准备或录音时停止，处理中忽略，完成或失败后可开始下一次。双击是立即向当前前台应用发送 Enter，不等待转录完成；要发送刚说完的文字，须先单击结束，等文字写入后再双击。

只独占该设备的媒体控制接口，不拦截其他键盘音量键，不占用 USB 音频接口。应用退出时释放；设备移除、重绑或退出时取消待执行单击，设备移除时清空按下状态，重新连接由 HID manager 发现。接管失败保留键盘触发并记录日志，不使用全局音量键替代。

释放和重复按下不重复触发；双击后 350 毫秒内的额外按下被忽略，避免三连击额外触发单击。单击判定期间前台应用发生变化时取消该次延迟动作，两个不同应用的点击不合并为双击。

验收：在 TextEdit 空白文档中双击，确认恰好一个换行且没有开始录音；连接键单击开始、再单击停止并写入文档，待文字写入后再次双击确认仅增加一个换行；核对系统音量未变化、键盘音量仍有效、按住只触发一次、拔插后恢复、退出应用后恢复原始音量动作。保留本地日志、按键与转录结果；未实测项目不得标为通过。

## 电源键边界

当前接收器连接下，实测“连接键 → 电源键短按两次 → 连接键”的对照序列，仅连接键产生 HID 输入及原始报告。电源键未暴露可映射的事件，因此不支持将其映射为 Enter，也不在听写结束后自动发送消息。该结论仅适用于已验证设备与当前连接方式。
