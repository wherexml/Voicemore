# DJI 接收器按钮

macOS 自动接管已验证的 `Wireless Mic Rx`（USB VID 11427 / PID 16401）的 Consumer Control 接口（Usage Page 12 / Usage 1）。连接键发出的 Volume Increment（233）每次按下触发一次听写切换；释放与重复按下不重复触发，与键盘“按住说话”设置独立。准备或录音时停止，处理中忽略，完成或失败后可开始下一次。

只独占该设备的媒体控制接口，不拦截其他键盘音量键，不占用 USB 音频接口。应用退出时释放；设备移除时清空按下状态，重新连接由 HID manager 发现。接管失败保留键盘触发并记录日志，不使用全局音量键替代。

验收：连接键短按开始、再按停止并写入前台文本框；核对系统音量未变化、键盘音量仍有效、按住只触发一次、拔插后恢复、退出应用后恢复原始音量动作。保留本地日志、按键与转录结果；未实测项目不得标为通过。
