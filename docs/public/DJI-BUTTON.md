# DJI 接收器按钮

已保存的旧 DJI 绑定接管已验证的 `Wireless Mic Rx`（USB VID 11427 / PID 16401）的 Consumer Control 接口（Usage Page 12 / Usage 1）。连接键发出的 Volume Increment（233）每次按下触发一次听写切换；释放与重复按下不重复触发，与键盘“按住说话”设置独立。准备或录音时停止，处理中忽略，完成或失败后可开始下一次。

通用设备按键路径以非独占方式打开控制接口，使用有真实来源匹配的 Quartz 辅助媒体事件，仅拦截已绑定的 Volume Increment 按下/松开；同接口未绑定键与其他键盘音量键保留原动作，USB 音频接口不接管。应用退出时释放；设备移除时清空按下状态，重新连接重新判断能力。无法确认可拦截事件时显示失败原因，不能退回整接口独占或全局音量拦截。完整支持边界与验收见[外接设备按键](DEVICE-BUTTONS.md)。旧的独立 DJI 原生监听 API 不属于当前设置入口路径。

验收：连接键短按开始、再按停止并写入前台文本框；核对系统音量未变化、键盘音量仍有效、按住只触发一次、拔插后恢复、退出应用后恢复原始音量动作。保留本地日志、按键与转录结果；未实测项目不得标为通过。

## 电源键边界

当前接收器连接下，实测“连接键 → 电源键短按两次 → 连接键”的对照序列，仅连接键产生 HID 输入及原始报告。电源键未暴露可映射的事件，因此不支持将其映射为 Enter，也不在听写结束后自动发送消息。该结论仅适用于已验证设备与当前连接方式。

## 双击硬件冲突

2026-10-15 实机验收中，用户确认双击发射器连接键会切换到蓝牙，原接收器链路失联。电脑侧无法阻止发射器固件先处理这一动作，因此撤回双击 Enter 映射及单击判定延迟，恢复单击立即切换听写。不要以重复快速按键作为 Enter 方案；后续方案必须先验证设备是否提供独立、无固件冲突的事件。

## 长按时长边界

2026-10-15 按短按、约 0.5 秒、约 1 秒的顺序实测，仅收到一组 usage 233 按下/松开报告，原生时间戳间隔约 1.98 毫秒；没有收到对应 0.5–1 秒的持续按住信号。当前接收器上报数据不足以可靠区分长短按，因此不实现长按 Enter，保留单击听写。此结论仅针对已验证设备及当前连接方式，不将瞬时 HID 脉冲当作物理按住时长。

## 原生设备按键设置（2026-10-17）

听写设置在顶部快捷键卡片之后、麦克风与声音之前显示通用“外接设备按键”，始终保留添加入口。通用设备选择、真实 HID 按键识别、多绑定、启用/移除与验收以[外接设备按键规格](DEVICE-BUTTONS.md)为准。旧安装的 DJI 映射保留，新增绑定不再使用固定 DJI 向导；DJI 的连接键、双击和长按硬件边界仍以本文实测结果为准。

## 配置迁移（2026-10-19）

全新配置和缺少 `djiButtonEnabled` 的旧配置均不生成 DJI 绑定。旧配置显式 `false` 不得被升级覆盖，显式 `true` 与通用设备绑定保持原值。版本号不能作为连接过硬件的证据。此前 schema < 6 的迁移曾无条件启用 DJI，可能在没有接收器的电脑上生成“DJI 无线麦克风”条目；这是外接设备按键绑定，不代表系统检测到了音频输入。

已被旧逻辑保存为 schema 6 / true 的配置无法区分自动迁移与真实用户选择，不能按“当前未连接”自动删除；不需要的旧条目可在外接设备按键中移除。麦克风选择独立使用系统枚举，明确保存过但离线的 UID 保留并标记未连接。

复验：`go run -tags dictationacceptance ./cmd/dictation-controls-acceptance > /absolute/evidence.json`，检查全新目录、旧版缺字段、schema 0/5/6 显式开关、保存重开与通用绑定，所有 `passed` 均为 true。该验收使用临时真实配置文件与 HTTP 控制器路径，不代表另一台 Mac 的原生界面或实体按键验收。
