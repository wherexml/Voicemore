# 全局触发键

Fn、右侧 Option / Command / Control 通过 macOS 只读事件监听触发，不依赖 Voicemore 主窗口是否在前台。其他快捷键仍由全局快捷键注册处理。

自定义组合键只有激活事件，始终按一下切换；旧配置即使残留按住模式也必须能开始、结束听写。引导可见时仍优先路由到引导；权限与模型步骤不得意外启动普通听写，练习步骤按实际可用的切换模式运行。保留已存的修饰键模式，切回 Fn 等修饰键时继续使用。

优先在 HID 层头部监听，以减少会话层其他快捷键工具造成的延迟或事件丢失；系统不允许该层级时退回会话层。不吞掉按键，不修改其他应用或系统快捷键。所需输入监控授权和应用签名身份保持不变。其他工具仍可能在更早位置处理按键，不能保证消除所有冲突。

监听被系统暂停或超时后，清除未完成的按键状态并重新启用。孤立的释放事件不触发切换；按住模式中已开始的手势按组合键释放规则结束，避免录音一直等待。监听初始化及中断恢复记录到应用标准日志，仅含触发键配置、层级和中断原因，不记录普通按键或输入文字。

## 原生验收

1. 以固定开发证书构建并核对安装包身份；不重置 TCC。检查全局监听已启用及实际监听层级。
2. 在其他应用前台、Voicemore 主窗口关闭或遮挡时，实按 Fn 开始、结束，至少连续十轮；核对胶囊与输入焦点。
3. 保留其他快捷键工具运行，切换应用、桌面空间后重复；分别检查快速单击与按住模式。
4. Fn+Delete 等组合不得触发切换；单独 Fn 下一次仍有效。
5. 验收进程中模拟监听中断，核对残留按下状态被清除、孤立释放不启动、下一次完整手势恢复。不要停用用户的系统权限来模拟。
6. 保存监听层级、按键次数、阶段变化和结果到本地 `artifacts/`，失败或未复现项如实记录。自动事件不能代替真实键盘验收。
7. 使用隔离设置注册自定义组合键，分别保留 hold 与 toggle 配置，检查原生激活事件都能进入听写；引导权限页可见时不得启动普通听写。原生合成组合键只验证注册与路由，不计为物理 Fn 验收。

## 禁用监听的主动恢复

除中断通知外，每 500 ms 在监听所在主线程检查真实启用状态。发现已禁用时清除残留手势并重新启用，避免系统未交付中断通知后 Fn 一直失效。健康监听不改变按下状态。停止或重新绑定时取消旧检查，并用代次隔离已经排队的回调。恢复不触发 toggle；hold 中断按组合释放收尾，孤立释放忽略。

原生自动复验：`go build -tags hotkeyacceptance -o /tmp/voicemore-hotkey-acceptance ./cmd/hotkey-acceptance` 后运行该程序并保存 JSON 输出。驱动创建真实系统监听、主动禁用并等待生产健康检查恢复，覆盖十轮完整手势、组合键、孤立释放、hold 中断和停止重绑。按键事件构造后直接交给生产回调，不向其他应用投递；这不代替物理 Fn、系统全局事件路由和完整听写验收。

绑定前必须以当前进程的输入监控 preflight 为准；未授权直接返回注册失败，不能把 macOS 返回的非零、但已剔除键盘事件的监听当作成功。已运行监听失去授权时暂停恢复尝试，仅记录一次缺失状态；授权恢复后再启用。系统设置中旧签名的开关开启不表示当前签名已获授权；先核对应用权限页、实际运行路径与签名，不重置 TCC。开发版与正式版身份切换后，应在系统设置刷新当前安装包的已有授权并按系统要求重开应用。

## 按键录入与翻译触发（2026-10-17）

听写设置顶部按触发键、翻译快捷键、目标语言、触发方式排列。两个快捷键均点击后直接按键录入，松开保存；首页保留标准选择器，可进入听写设置录入自定义键。支持 Fn、左右 Option/Command/Control/Shift 单键、F1–F20、⌘⇧K 等组合键、仅修饰键组合与 Fn 组合。普通字母、数字、标点、输入与导航键必须搭配 Command/Control/Option/Fn，Shift 单独不算；拒绝裸 A、Shift+A、Enter、Space 等会占用正常输入的绑定。仅修饰键组合保留左右键身份；Fn 组合与仅修饰键组合走只读原生事件监听，普通组合仍走系统快捷键注册。组合键按一下切换，单独修饰键沿用听写的切换/按住方式；翻译始终按一下切换。

录入只在设置窗口内进行，使用消费事件的 AppKit 本地监听；录入期间暂停原有全局键盘及设备触发。Escape、Tab、窗口失焦、点击外部、切换分类和关闭窗口均取消，保留原值。Fn 等实际按键仍需物理键盘复验。两项相同（包括已存 accelerator 别名）时拒绝，首页禁用已被翻译占用的选项，引导同样拒绝冲突；系统注册失败时回退原配置与绑定并显示原因，不用其他按键代替。翻译快捷键可清除；清除后释放其全局注册。

翻译快捷键和 DJI 翻译动作共用[翻译听写流程](TRANSLATION.md)。目标语言在没有翻译快捷键或 DJI 翻译动作时禁用。设备设置见 [DJI 接收器按钮](DJI-BUTTON.md)。

复验：实际设置窗口分别录入单独左右修饰键、Fn 和组合键；确认录入时不启动听写，松键保存，重复/自动重复不二次启动；测试 Escape、Tab、失焦、关闭、切分类和重复键拒绝；关闭并重开应用核对保存与全局注册。保留其他应用前台时的实际触发、原生截图与失败原因。协议和 native listener 验收程序不能代替物理 Fn/DJI 及完整录音写入证明。

组合键补充复验：录入 ⌘⇧K、⌃⌥、Fn+K，分别松开普通键优先与修饰键优先，确认显示、保存与重开一致。仅按部分键、自动重复、额外修饰键/普通键、孤立释放及监听中断不得误切换；普通方向键不得被识别成 Fn 组合。录入中的按键不得启动听写。仅修饰键与 Fn 组合仍须物理按键单独复验。

录制预览、设置保存和启动注册共用 `config.ValidateShortcut`。旧配置中危险绑定不注册并显示错误，但允许修改其他设置以及改回安全键；不自动抢占替代键。翻译快捷键仍可清除。

安全复验：先运行 `scripts/verify-integrity.sh` 验证两种快捷键保存与重开、别名、非法键与旧配置修复；再编译 `go build -tags integrityacceptance -o <独立开发夹具的可执行路径> ./cmd/shortcut-recording-acceptance`，以指定开发身份和独立 Bundle ID 签名，运行 `-output <全新隔离目录>`。用 CUA 激活窗口空白区域，点击 Record shortcut 后录入 A、Shift+A、Enter、Space（应拒绝且旧值不变）、⌘⇧K（应保存）、Escape/Tab（应取消）；最后点 Finish verification，核对真实 macOS 安全组合键注册与重开检查。该夹具不注册危险键，不监听全局键盘、不录音、不替换正式 App；CUA 按键不算物理 Fn 验收。逐项结果为目录内 results.json。

运行 `python3 scripts/verify-shortcut-evidence.py <隔离目录>/results.json` 校验完整操作记录，缺少拒绝/保存/取消/注册/重开证据时非零退出；Escape 和 Tab 的对应关系须同时核对 CUA 操作顺序。
