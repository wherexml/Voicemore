# 远程桌面输入规格

入口为“设置 → 通用 → 远程桌面”。本功能通过客户端已有的剪贴板同步与粘贴快捷键工作，不建立远端连接，也不安装远端代理。用户先在客户端开启剪贴板同步，再点击远端输入框开始听写。

## 配置与匹配

从已运行应用列表添加客户端，可刷新列表；仅列出有 Bundle ID 的普通桌面应用，排除 Voicemore 自身，不内置客户端名单。新增规则默认关闭、等待 1500 ms；用户选择 Command+V (⌘V) 或 Control+V (⌃V) 后启用。按客户端手动粘贴时有效的快捷键选择，不按远端操作系统命名；例如连接 Windows 的客户端也可能使用 Command+V。

匹配使用 Bundle ID 精确相等和窗口标题的大小写敏感子串。空标题匹配该客户端全部窗口；多个匹配时，标题条件最长者优先，同长度由后面的规则覆盖。更具体的关闭规则可以覆盖客户端通用规则，关闭表示回到普通本地写入路径，不是禁止听写。

UI 提供 0.5、1、1.5、3、5 秒等待，执行层限制在 200–10000 ms，等待从第二次剪贴板写入后计算（首次写入后另有约 450 ms 刷新间隔）。 该等待仅为同步预留时间，并非远端确认；网络或客户端未完成同步时仍可能粘贴上一段内容，不能以本机剪贴板版本未变化推断远端已更新。字段及持久化约定见[配置模块](../../internal/config/README.md)。

## 写入与历史

1. 会话在写入时捕获当前前台目标，将本次设置中的规则传给 macOS 写入层。
2. 匹配启用规则后，把文字放入剪贴板并检查写入返回值与读回内容。约 450 ms 后，仅在焦点与剪贴板版本仍属于本次输入时重新发布同一句，给可能漏掉第一次更新的客户端再次同步的机会。任一次写入失败都停止粘贴；用户中途复制的新内容不会被覆盖。保留文字用于异步同步，不恢复原剪贴板。第二次发布不代表远端确认，仍须连续不同句实测。
3. 等待期间约每 25 ms 检查取消、辅助功能授权、前台进程、焦点窗口和剪贴板版本；若最初能获取焦点元素，也核对该元素未变化。
4. 任何检查失败都不发送粘贴；已写入剪贴板的文字不主动恢复。正常校验失败返回剪贴板回退，取消走会话取消路径；用户后来复制的新内容保持不动。
5. 最后再次核对，再发送修饰键按下、V 按下、V 松开、修饰键松开的事件。使用通用修饰键标志及对应左侧设备标志（Command: `0x100008`，Control: `0x40001`），各事件间隔 30 ms，使依赖左右键状态的远程客户端也能识别组合键。 AppKit 目标校验仍在主线程执行，CoreGraphics 投递和事件间等待在调用工作线程执行，避免阻塞本机热键监听的主线程 run loop。仅有通用标志时，Windows App 实测会转发成普通 `v`。

成功发送时 `Remote=true`，历史使用现有 inserted 状态，但详情明确“尚未确认远端输入；剪贴板已保留用于同步”。不得将此状态解释为远端文字已验证。远程路径跳过插入后的修改观察和词典学习。没有匹配启用规则时，继续既有本地输入及剪贴板恢复流程。

## 可重复原生 E2E 验收

使用 AGENTS.md 指定证书构建；启动前核对签名与 designated requirement。准备实际远程客户端、一个远端空白文本框和本地 TextEdit，使用无敏感信息的固定短句“远程输入验收 42”。

| 场景 | 操作与预期 |
| --- | --- |
| 默认关闭 | 添加客户端后重开设置，确认规则仍关闭、等待为 1.5 秒；关闭规则不启用远程路径 |
| 匹配优先级 | 添加通用规则、特定连接标题规则和同长度重复规则；验证最长标题优先、同长度最后一条优先，特定关闭规则覆盖通用启用规则 |
| 两类快捷键 | 分别验证 ⌘V 与 Ctrl+V 及客户端映射；人工读取远端文本确认实际结果，历史仅声明快捷键已发送 |
| 等待保护 | 设 5 秒，在等待期间分别切换应用、切换窗口、更换焦点、复制另一段文字、取消；确认不发生远端粘贴，新复制内容未被覆盖 |
| 连续不同内容 | 在同一连接连续听写三句明显不同的短句，逐次核对本机识别记录与远端实际内容；不得出现上一句、重复句或空输入。测试时不手动粘贴。增加等待后必须重跑，不能仅凭延时数值宣布同步可靠 |
| 同步关闭 | 关闭客户端同步，确认不能把历史状态当成远端插入成功，记录远端实测结果 |
| 本地回归 | 移除或关闭规则，在 TextEdit 听写，确认本地写入和原剪贴板恢复按原逻辑工作 |
| 修改观察 | 开启观察后完成远程发送，确认未启动远端读回学习 |

每次执行在 `artifacts/remote-input/` 保存结果表、客户端版本/映射方式、构建提交、签名核对结果、本地与远端截图及历史详情。对剪贴板和焦点保护逐项记录，不以构建成功代替 E2E 结论。

### 自动化原生投递验收

运行 `./scripts/verify-input.sh`。脚本使用本机约定的开发证书签名验收程序与原生窗口 fixture，不修改或发布 Voicemore 安装包。测试会临时聚焦 fixture 并使用剪贴板。结果写入 `artifacts/remote-input/native-results.json`，失败时返回非零状态。

覆盖本地当前焦点、不可编辑控件、自绘编辑器、剪贴板恢复，以及远程 ⌘V／Ctrl+V 实际键盘事件、取消、更换剪贴板和切换焦点保护。fixture 不模拟网络同步，不能替代远端实测。

准备好真实远端空白输入框后，可直接调用生产插入路径（替换 Bundle ID 和快捷键）：

```sh
artifacts/remote-input/input-acceptance --remote \
  -bundle CLIENT_BUNDLE_ID -shortcut cmd-v -delay 1500 \
  -text '远程输入验收 42' -out artifacts/remote-input/dispatch.json
```

程序要求指定客户端已在前台、当前验收进程已有辅助功能权限。`-shortcut ctrl-v` 检查 Windows 快捷键；`-cancel-after 200` 检查同步期间取消。JSON 只证明投递结果，必须同时读取远端屏幕并保存截图确认文字，没有按回车或发送的步骤。麦克风、ASR、物理 Fn 仍需独立整链路验收。

加上 `-sample /absolute/path/sample.wav -asr http://127.0.0.1:48132` 可执行固定语音录音 → 真实 ASR → 自动远程粘贴。使用实际配置的本地 ASR 地址；音频必须为 PCM16、单声道、16 kHz WAV。报告包含样本 SHA-256 和识别结果，空识别结果或识别结束时客户端不在前台会终止，不粘贴。

这项录音回放验收调用生产 ASR 客户端和插入代码，但不经过已安装应用的物理麦克风、Fn、整理模型或会话 UI。完整客户端验收须另外使用本机 Voicemore，在远程输入框聚焦时按 Fn 说出固定短句，再按 Fn 结束；核对本机历史记录的目标客户端和远端实际文字。被控端不需要安装或运行 Voicemore。
