# 开始使用引导（V6）

入口：`onboarding.go`、`onboarding_bridge.go`、`resources/onboarding/`。设计依据为本地 `mock/onboarding-v6.html`，模型步骤依据已确认的 `mock/onboarding-model-v2.html`。

## 页面与原生边界

- 720 × 540，最小 620 × 480；内嵌 WKWebView 加载打包资源，不启动 HTTP 服务。
- 五步：权限 → 语音模型 → 快捷键 → 练习 → 完成。
- 流动光带、黑色透明蒙版、液态玻璃卡片与 SVG 图标。底栏与背景连成一体，没有“稍后设置”。系统关闭按钮返回首页。
- Fn 首次提醒复用已确认 mock：快捷键卡片下方居中 11 px 弱化单行“Fn 组合键不受影响，退出后恢复原功能。”；无弹窗或额外按钮。仅绑定成功且未确认时展示，继续后保存一次性状态，返回/重开不重复。
- Fn 默认，按一下默认且在左侧；保留用户已有触发键和模式。检测成功使用整个键帽的玻璃选中态，不显示角标或可见状态文字。
- 权限、下载、快捷键与练习均由原生状态驱动，页面没有模拟成功入口。
- 本地资源仅允许本窗口调用桥；页面跳转被限制为本地入口。

## 模型与练习

模型页使用左右并列的本地/云端选择卡片；不展示量化位数和重复说明。本地未安装时在卡片下方同一区域显示预计体积与“下载模型”按钮；下载中展示真实字节进度，允许取消；已安装时显示启动按钮；就绪后可设为默认。云端入口打开原生模型设置。只有实际可用且来源与当前本地/云端选择一致的默认语音模型才能继续，前端和原生桥同时校验。

快捷键页更改配置会重新注册并清除检测状态。必须收到真实原生按键释放事件才解锁下一步。组合键不会作为成功检测。

练习使用既有 `StartPractice` 录音识别链路，结果只交给当前引导，不写入其他应用。处理期间禁止继续；退出步骤或窗口时取消并丢弃迟到结果。练习区只读，防止输入与异步转写互相覆盖。模型不可用时提供设置入口。

进度保存在 `config.Onboarding`，布局版本为 7（V6 的五步布局）。从四步试用布局升级时回到模型页，保留已检测快捷键并要求重新练习。历史用户仍从设置打开，不强制弹出。

## 刷新与动画

状态检查每 250ms 一次，仅按固定顺序比较实际展示字段；不依赖桥返回对象的字段排列。无变化时保留 DOM，不重播动画。权限对号和选中键帽不使用入场动画。模型进度只在模型页参与比较。

背景使用高分辨率 Canvas/WebGL 流动纹理；页面隐藏或系统减少动态效果时暂停。引导固定使用深色液态玻璃，不随应用外观设置切换；其他窗口仍遵循应用外观。

## 可重复原生验收

1. 固定本机开发证书构建、核验签名及应用身份，安装后从设置 → 通用 → 打开指引进入。
2. 权限页核对实际系统状态；连续观察对号，无周期性闪烁。不要为测试随意撤销已有权限。
3. 模型页检查已安装启动 → 加载中 → 就绪；新安装环境另验下载字节进度、取消、重试与失败提示。已安装环境不得宣称验证了首次完整下载。
4. Fn 真实按键检测后，键帽持续玻璃选中，无角标。检查按一下/按住顺序与配置保存。
5. 练习使用真实音频：开始 → 结束 → 文本 → 继续 → 完成 → 首页；检查取消、返回和关闭不产生迟到写入。
6. 重开确认步骤保留；检查引导固定深色、语言和最小窗口布局。
7. 截图、构建日志和逐项 PASS/FAIL/BLOCKED/NOT_RUN 结论保存在忽略目录 `artifacts/onboarding-native-v6/`。测试结论以该次证据为准。
