# 开始使用引导

实现入口：`onboarding.go`。引导包含使用方式、语音模型、权限和第一次听写四步。设计来源是 `mock/claude.html` 的引导（默认 Flat 表面），设计记录见 `mock/onboarding-design.md`。

## 窗口与布局

- 默认窗口尺寸为 1040 × 600，最小尺寸为 900 × 480（逻辑像素），未改变。
- 标题栏只保留系统窗口按钮，不显示标题文字，与窗口同一表面，可拖动窗口。
- 不再有横向四步导航。每一屏只有一个焦点，依次为：
  - 步骤图示；
  - “第 n 步，共 4 步 · 步骤名”；
  - 标题；
  - 该步骤唯一要做的事。
- 内容左右各留 48 内边距，水平居中。
  - 前三步与完成页的内容列最宽 540。
  - 第一次听写保留原有规则：练习区随窗口宽度伸缩，不设宽度上限，左右留白相等。
- 内容按上一帧测得的高度，在标题栏与底栏之间垂直居中，因此有一帧延迟。内容高于可用高度时（例如最小窗口高度）从顶部开始，可以滚动。
- 底栏高 64，只有一条细分隔线：
  - 左侧是无边框的“上一步”，第一步不显示；
  - 中间是四个进度点，当前步骤为短横条，已完成的颜色较深，点击可跳到对应步骤；
  - 右侧是无边框的“稍后”和唯一的主按钮（继续 / 完成 / 进入 Voicemore）。
- 底栏不再显示“尚未完成”。语音模型与权限两步未完成时，“继续”仍然禁用（原有规则），原因以一行灰色说明（`obNeedStep`）显示在该步内容下方。

## 各步骤

- **使用方式**：三行操作放在下沉底色的圆角区域中，每行左侧是 64 宽、居中且裁剪的图示列。
  - 第一行：触发键键帽。
  - 第二行：当前所选样式的听写胶囊缩略图。靛蓝样式与 `overlay_v2.go` 同色，有五根 3 宽的音量条，最后一根为薄荷色；经典样式为黑色胶囊和波形。
  - 第三行：文字插入图标（几行文字加光标）。
- **语音模型**：两个选项卡片，选中项为下沉底色。所选分支的状态与操作（下载、启动、取消、设为默认，或打开语音服务商）放在其下的下沉区域。
- **权限**：按顺序逐项展开。
  - 已授权的行收起为一行，带勾号。
  - 第一项未授权的权限为焦点：显示用途说明，按钮为主按钮。
  - 其后未授权的项变暗，只显示普通按钮。
  - 麦克风、辅助功能、输入监控的按钮均为“请求权限”。麦克风被拒绝后为“打开系统设置”，与之前相同。辅助功能和输入监控仍打开[权限拖拽引导](PERMISSIONS.md)。
  - 重启提示（`permHint`）、拒绝提示和“三项权限均已授权”保持不变。
- **第一次听写**：
  - 语音模型或权限未就绪时，练习区上方显示提示“请先完成语音模型与权限。”，并逐项列出缺少的步骤及其状态，每项带“前往”按钮。
  - 练习区为 4–8 行的输入框，带占位文字，下方一栏显示录音状态与操作。练习听写不会写入其他应用，也不使用剪贴板，与之前相同。
  - 第一次练习成功后，上方以淡入方式显示“第一次听写已写入。”，练习区边框短暂变为绿色后保持浅绿，主按钮变为“再试一次”。开启“减少动态效果”时没有动画。
- **完成**：居中显示勾号、“Voicemore 已设置完成。”和触发键说明。底栏为“查看步骤”和“进入 Voicemore”。

步骤图示：
- 使用方式：应用图标；
- 语音模型：语音变文字的线稿，四根音量条加三行文字；
- 权限：已打开的系统设置开关线稿；
- 第一次听写：触发键键帽。

两个线稿用当前主题的文字色原生绘制，与 `mock/assets/onboarding-speech-to-text.svg`、`onboarding-allow-switch.svg` 的几何一致。

进度保存、各步骤完成规则、练习运行与权限状态读取均未改变。新增文案：`obStepOf`、`obStDone`、`obStTodo`、`obAgain`、`obFix`（三种语言）。

## 原生验收

以下是可重复的验收步骤，列在这里不代表已经执行。

1. 使用固定开发证书构建并启动客户端，从设置 → 通用 → 设置指引打开引导。
2. 在默认尺寸和最小尺寸（900 × 480）下逐步检查：
   - 标题栏无文字；
   - 图示、步骤行、标题与内容完整可见，无重叠；
   - 默认尺寸下内容在垂直方向居中；
   - 最小尺寸下可以滚动，底栏始终可见。
3. 使用方式：在设置 → 通用切换听写胶囊（靛蓝 / 经典），确认第二行缩略图随之变化，且三个图示都在 64 宽的列内。把触发键改为“右侧 Option”等长名称，确认键帽不越界。
4. 语音模型：在未部署、下载中、就绪、出错四种状态下确认下沉区域中的状态与按钮；在云端分支打开语音服务商后再关闭设置，确认回到引导。
5. 权限：撤销三项权限后重新打开引导。
   - 确认第一项为焦点（主按钮）、其余变暗，按钮文字均为“请求权限”。
   - 依次授权，确认已授权的行收起、焦点移到下一项。
   - 确认辅助功能和输入监控打开拖拽引导，且其行为不变。
6. 第一次听写：
   - 在权限未全部授权时用进度点跳到该步，确认提示列出缺少的步骤，“前往”跳到正确步骤。
   - 授权后完成一次练习，确认结果行出现、边框变绿、按钮变为“再试一次”。
   - 开启“减少动态效果”后再试一次，确认没有动画。
   - 拖宽窗口，确认练习区同步变宽、左右留白相等。
7. 在英文、繁体中文、简体中文三种语言及浅色、深色主题下，重复第 2、5、6 步并截图。
8. 关闭再打开引导，确认停在上次的步骤且已完成状态正确；完成全部步骤后确认显示完成页。
9. 将截图、构建信息和实测结论保存到本地 `artifacts/`。
