# 外接设备按键

听写设置始终显示“添加设备按键”，包括已有绑定时。空态和标题右侧均能添加。绑定列表兼容多个设备与已有同设备不同按键的配置，分别启用、修改动作、重新识别、测试和移除。添加页允许再次选择已有绑定的设备，为不同按键独立设置听写或翻译；使用“修改”编辑或重新识别当前这一条绑定。

添加分三步：选择真实连接的设备 → 实按要使用的按键 → 选择切换听写或切换翻译并保存。设备能力按实际 HID 描述符与可拦截系统事件判断，不按品牌放行，也不显示虚构的脚踏板或遥控器。支持鼠标中键/侧键、外接键盘/小键盘的普通键及具有系统事件映射的媒体控制键。标准 HID 脚踏板、遥控器使用相同流程；私有协议、游戏控制器等无法逐键接管的接口明确标为“暂不支持逐键接管”，禁止选择和保存。仅有左右键的鼠标显示无可绑定辅助按键；音频端点显示“暂不支持按键绑定”。修饰键、锁定键及未映射的特殊键不能通过此入口绑定，识别时显示“此按键暂不支持接管”。不把设备连接状态等同于接管能力。USB/Bluetooth 的外部接口只读发现；内置、SPI、FIFO、音频传输的 HID 不作为可接管目标。

同一物理复合设备合并显示，优先鼠标、键盘、媒体接口；分组使用 VID/PID、传输及序列号或物理位置，名称不作为绑定身份；两个非零连接位置不同，即使厂商复制了同一序列号也保持分开。采集时非独占打开该设备支持的接口，收到事件后保存真正发出事件的接口身份，因而鼠标的键盘宏接口也可经同一设备入口识别。同名但身份不同的设备不合并。音频端点仅作为不可绑定信息行按名称去重。

所有通用 HID 接口都以非独占方式打开，不再通过整接口独占来拦截一个媒体键。鼠标辅助键、普通键盘键、可映射媒体键共享可修改 Quartz tap：事件 sender 必须通过 IORegistry 祖先链对应已打开的真实 HID 接口；仅消费该接口已启用绑定键的按下/松开，随后从成功消费的按下分发一次动作。自动重复不重复触发，松开不触发动作。未绑定、停用、移除的键和其他设备同编号键直接放行；移动、滚轮、左右键和修饰状态不在拦截掩码内，不重建或重放普通输入。向导采集只消费选中物理设备可支持的按键，不启动录音；原生 HID 回调只反馈不支持的采集尝试或诊断信号，不触发听写。键盘按物理扫描码对应 HID Usage，不根据输入法文字猜键；媒体事件只识别 NX_SYSDEFINED 的辅助控制子类型及已映射键，其他系统事件放行。

sender 是系统非公开元数据，缺失或无法匹配时放行，不扩大为全局同键拦截。如果真实 HID 信号未得到成功消费的对应系统事件，诊断显示“系统未提供可拦截事件”，不能保存。诊断时间窗仅用于报错，不推断设备来源或触发动作。无权限或无法创建修改监听时显示接管失败；中断尝试恢复。重绑保留已消费按下到对应松开，断开时清理。接口身份由 VID/PID、位置、序列号、传输、Primary Usage 和 Report Descriptor 指纹构成，不使用枚举顺序或临时指针。旧身份只在唯一匹配时兼容，歧义拒绝接管；拔插后重新判断能力和歧义。

向导按 mock 使用 490 DIP 面板、图标设备卡片、单选边框、圆形三步标记、底部分隔线和主按钮；列表可滚动。已有绑定的设备在选择列表仍可选择，不因设备已添加而禁用。修改直接进入绑定动作页，重新识别可回到第二步。绑定卡片显示设备图标、状态、开关、移除、按键到动作及测试/修改。测试在原卡片下反馈，不打开向导；12 秒超时、取消或关闭设置均恢复原触发，即使切换设置分类也会超时恢复。

识别等待 12 秒，可重试；未连接、接管失败或未收到真实事件时不能保存。采集期间暂停已有设备与键盘触发，收到事件只更新向导，不启动听写；退出向导恢复原有绑定。按键 usage page/usage 与设备身份一起保存，重复按下不重复触发；相同设备的同一按键不能重复绑定，包括已停用绑定；识别到已绑定按键时显示“此按键已绑定”并禁用下一步，重新识别到其他按键后可继续。编辑本条绑定时允许保留自身按键，保存时再次校验能力、连接状态与冲突。动作使用按一下切换，不根据未经验证的 HID 脉冲虚构长按能力。

`deviceButtons` 保存新绑定；旧 `djiButtonEnabled`/`djiButtonAction` 在兼容层表现为一条旧绑定。修改/停用该绑定时写入通用集合，保留既有功能；移除不会在重开时自动添加。任一已启用设备使用翻译动作时，目标语言可以设置。

## 复验

1. 已有绑定与空态都应看到添加按钮；关闭重开仍可添加。同一鼠标按键 4 绑定听写后，再次添加仍可选择该鼠标，将按键 5 绑定翻译；重开后两条动作各自保留。再次按已绑定按键时禁止继续，编辑本条自身按键不冲突，停用或移除一条不能改变另一条。
2. 对照真实 HID 与蓝牙音频枚举和选择页，AirPods 只显示一条并禁止绑定；不能用模拟名称或截图证明设备已接管。浅色/深色下核对卡片、步骤、选中态、操作按钮及滚动。
3. 选择、返回、取消、关闭；未选设备/未收到事件/断开/接管失败时不能继续保存，重试能重新申请接口。
4. 使用实体按钮识别、保存，重开后按一次开始、再按停止；期间音频输入不受影响。记录实际设备、按钮、动作、系统原动作是否被抑制及转录结果。
5. 多绑定的持久化、快照隔离、停用/移除与翻译目标启用：`go run -race -tags dictationacceptance ./cmd/dictation-controls-acceptance`。
6. 被动设备发现：`go run -tags devicebuttonsacceptance ./cmd/device-buttons-acceptance`；不打开任何 HID 接口，不代表物理按钮或语音链路通过。
7. 对复合设备（如 Razer Basilisk X HyperSpeed），原生枚举核对各接口 ID 不同且无身份冲突；添加列表只显示一条“鼠标”，侧键来自 Primary Usage 1/2 接口；若用户自定义固件从附属键盘接口发出普通键，采集后保存实际键盘接口，不能按代表行类型强行改写。用 `-capture <完整接口ID>` 验证单独打开、停止与重开；加 `-legacy` 验证旧绑定，唯一接口兼容，多接口旧身份须返回歧义错误。此命令不注入按键，也不代表实体按钮已收到。增加 `-listen 120s -events 2` 等待两次实按并输出真实设备、Page、Usage；必须看到鼠标 Page 9、Usage 4/5 的事件后才可声称侧键收到。期间移动、左右键与滚轮不得产生被识别事件，连续按住不重复触发；松开后再次按下应再收到一次。

8. Chrome 独立测试页建立 1→2→3 后返回 2，保证前后都有历史。启用鼠标 4/5 绑定时，分别实按后页面仍停留 2，真实回调收到两个事件且按下/松开消费数成对；停用对应绑定后该按钮可恢复前进/后退。验收工具 `-capture <鼠标接口ID> -bind-buttons 4,5 -listen 30m -events 2 -stop-file <尚不存在的结束标记路径>` 使用普通绑定模式，记录回调与 `mouse_interception`，不启动录音；只设置一个按钮时应放行另一个。工具须保持运行到实按完成、页面状态记录并收到用户确认，再创建结束标记；提前退出后的按键会恢复系统动作，不能归为持续拦截失败。检查消费数按下/松开成对、无待释放按钮及无 race 报告。

本地证据保存在忽略目录 `artifacts/device-buttons-*/`，不入库。构造数据、配置验收及模拟页面不能替代实际按钮确认。

9. 能力与反例：`go run -race -tags devicebuttonsacceptance ./cmd/device-capabilities-acceptance`。保留真实描述符、支持/不支持原因、复合设备分组及 23 项策略反例结果；这些不替代物理输入验证。
10. 键盘选择性拦截：临时普通绑定模式 `-capture <键盘接口ID> -bind-keys 7:13 -listen 30m -events 1 -stop-file <新结束标记>` 将物理 J 绑定到仅记录回调，K 不绑定。Chrome 输入框实按 J/K 时仅出现 K；确认 J 的按下/松开消费成对、无重复动作，其他键盘同键仍正常，结束监听后 J 恢复输入。不得用程序注入替代实体来源证明。
11. 媒体选择性拦截：`-bind-keys 12:233` 仅接管该接收器音量增事件，音量减/其他设备音量键保持原动作。记录真实来源、消费次数、系统音量前后值及无录音副作用；无法建立来源时必须保持原动作并显示原因，不能退回整接口独占。已有 DJI 兼容绑定也走相同通用路径。
