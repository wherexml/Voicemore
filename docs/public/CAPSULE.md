# 听写胶囊

## 提示音后的聆听状态（2026-10-18）

启动时保留无文字的静止波形，不显示“准备中”。收到首包PCM、开始提示音完整播放结束且所需静音已生效后，进入“正在聆听”；不等待ASR建连，也不以已有识别文字或语音能量为条件。准备期间的PCM完整缓冲并发送，不得清空。关闭提示音时仍须等待实际PCM就绪；早停、取消或设备失败不能被迟到回调重新切回聆听。

复验须在提示音后立即说固定样本，逐字核对开头与末尾。内部准备阶段仍可取消，但不显示该文案。

默认靛蓝胶囊的关闭按钮初始隐藏。鼠标进入胶囊及其左侧关闭区域后显示；移出后保留 500 毫秒，再用 200 毫秒动画收回。新一轮听写不得沿用上一轮的悬停状态。原生窗口按当前屏幕鼠标位置判定悬停，并定期刷新，包含启用“减少动态效果”和结果提示静止时。

录音胶囊不显示右侧“结束并写入”对号，使用已配置的触发键结束录音。胶囊不显示说明浮层；鼠标悬停关闭按钮时，只在按钮上方显示 `Esc`。窗口为提示预留顶部空间，胶囊底部位置不变。

键盘导航聚焦关闭按钮时保留关闭入口。开始写入文字后不提供取消。

胶囊在显示期间跟随当前操作屏幕：鼠标跨屏时切换到鼠标所在屏幕；鼠标未跨屏而前台窗口切换或移动时，跟随该窗口所在屏幕。每 200 毫秒检查一次，静音、静止结果和“减少动态效果”下同样生效。始终保持屏幕底部居中及已有底部间距，展开预览不改变胶囊底部位置。窗口跨 macOS 桌面空间及全屏空间显示，保持浮层层级，不激活应用、不抢输入焦点。隐藏后停止跟随，下一轮重新初始化。

## 原生验收

1. 鼠标停在屏幕上方，开始听写：关闭按钮不可见。
2. 移到胶囊：关闭按钮出现；移到关闭按钮的途中不应消失。
3. 移开，等待至少 800 毫秒：关闭按钮不可见。
4. 鼠标在关闭区域结束上一轮，再移到屏幕上方开始下一轮：关闭按钮仍应隐藏。
5. 悬停关闭按钮：上方只显示 `Esc`，不显示“取消”，不出现下方注释；录音时右侧无对号。关闭按钮显示时点击：取消听写且不写入文字。
6. 开启系统“减少动态效果”，重复以上步骤；转写结束的静止提示也须正确响应移入和移出。
7. 用键盘导航聚焦按钮，核对可见性；写入阶段不出现关闭按钮。

8. 双屏开始听写，鼠标跨屏：胶囊在约 200 毫秒内跟随；两种胶囊样式、展开预览、静音和静止结果分别复验。
9. 鼠标保持不动，用键盘切换到另一屏的应用，或切换同应用的窗口：胶囊跟随前台窗口；在目标输入框继续打字，焦点不被抢走。
10. 听写期间切换桌面空间、进入和退出其他应用全屏：胶囊持续可见且位于应用窗口上方；取消后不得再次出现。
11. 显示期间拔掉外接屏、调整 Dock 位置：胶囊仍在有效屏幕底部；连续取消并重启听写不出现旧位置回跳。

保存每次验收使用的构建信息、截图与实测结果到本地 `artifacts/`。渲染器截图不能代替原生窗口鼠标事件验收。


## HTML 连续状态动效（2026-10-17）

本节记录 `mock/capsule-states-v2.html` 的已选动效基线。原生同步规则见下文，发送语义仍遵循[自动发送规格](AUTO-SEND.md#v14-原生连续胶囊2026-10-16覆盖旧浮层流程)。统一导航的胶囊入口预选文字整理与自动发送，便于重播完整流程；不带参数打开时两项仍默认关闭，支持 `?tidy=1&autoSend=1` 预览参数。

- 准备、聆听、转录、整理、写入、倒计时和结果复用同一胶囊与波形节点。外壳高度固定 40 px，连续阶段固定底部锚点，仅首次出现及最终退出做轻微上移与淡入淡出。
- 外壳、正文空间、左侧图标槽及发送控件的宽度统一采用 480 ms、`cubic-bezier(.32,0,.2,1)` 的缓动。按目标内容测量宽度，不用过渡中的尺寸反复推算下一个目标。正文收起时保留淡出的文字，避免内容提前清空。
- 旧状态文字在 160 ms 内向上 4 px 淡出；新文字延后 80 ms，以 300 ms 从下方 5 px 淡入。仅阶段或语言改变时执行，倒计时的小数更新不重复播放。
- 波形节点持续存在，通过可插值的振幅参数收为短条，避免录音动画重启；波形、整理星芒与结果符号采用透明度及小幅位移交叠。
- 写入转倒计时时，左侧图标槽收起，Esc 与圆环叉号的空间连续展开。完整倒计时从进入阶段开始计算，环形进度不额外等待动画；等宽数字及预留宽度避免计时跳动。Escape 或叉号取消后保留已输入文字。
- 快速切换要清理旧文字层；重播重置倒计时与进度环。“暂停动效”及系统“减少动态效果”直接呈现最终状态，结束仍在运行的有限过渡。英文与窄屏不得裁切取消按钮。

复验：在统一导航打开胶囊，点击“开始演示”，检查全部阶段连续过渡；取消后重播，再检查仅输入、整理失败重试、快速状态切换、英文窄屏、暂停动效与系统减少动态效果。可重跑 `artifacts/capsule-motion/e2e.mjs`，将故障场景、逐帧几何/透明度、结果 JSON 与截图保存在同目录。HTML 验收不代表原生已应用本轮动效。


## 原生连续状态动效（2026-10-17）

靛蓝胶囊在 `overlay_v2.go` 与 `overlay_motion.go` 复用同一绘制子树，发送倒计时也使用 `v2wrap`、`v2pill`、`v2body`。不再仅复用窗口却切换至另一段胶囊绘制逻辑。经典胶囊保留原有样式。

- 宽度使用与 HTML 相同的 480 ms 贝塞尔曲线；图标槽、状态文字、行内正文和发送控件各自插值，外壳随这些空间连续伸缩，高度及底部锚点固定。
- 状态文字保留离场层，按 160 ms 淡出、80 ms 延迟加 300 ms 淡入；快速变化从当前透明度及位移接续。倒计时只更新现有文字，预留完整行宽。
- 波形仍使用真实麦克风电平；进入转录时，其已显示的高度渐变收为短条。星芒、对勾及异常符号交叠显示。行内文字在渐隐与收拢期间保留，不提前清空。
- Esc 和圆环叉号随胶囊展开，取消与到期仍只作一次决定；倒计时从进入发送阶段开始，不扣除入场动画，也不追加等待。发送结束或取消后做 220 ms 退场，旧回调不能隐藏新一轮胶囊。
- 系统“减少动态效果”直接使用目标尺寸与清晰状态，不等待内容动画；关闭仍保留既有事件及目标保护语义。弹出层不激活应用，持续保留目标输入框的键盘焦点。

原生复验使用 `VOICE_INPUT_SEND_PREVIEW_ACCEPTANCE` 专用夹具：`flow` 重放准备至写入后，仅向已捕获的专用夹具 AX 字段写入文字并运行真实倒计时，`flow-fast` 验证短阶段的连续接续，`start-slow` 与 `flow-slow` 留出取消操作时间，`input-only` 验证只输入。该模式只注册生产 Escape 监听，不绑定听写触发键或 DJI。绘制遥测记录胶囊实际布局、各槽宽度、图标与文字层透明度；窗口信息及夹具正文、发送决定必须共同核对，不能只断言插值数值。

本地证据目录 `artifacts/capsule-native-motion/` 保存先列出的故障场景、可重跑 `e2e.py`、原生截图、逐帧 JSON、签名身份、安装前后摘要与结果。夹具不派发全局粘贴或 Enter，避免前台竞争时误输入；模拟阶段不代表生产粘贴/发送键、物理按键、麦克风或 ASR 识别质量验收。安装包使用既有本地开发签名，不据此宣称正式发布、公证通过。

## 错误提示自动退出（2026-10-19）

所有听写 Failed 状态（识别、整理、设备、写入和历史保存失败）的胶囊与详情统一显示 3 秒，随后使用既有 220 毫秒退场动画一起隐藏。经典与靛蓝样式共用计时，不依赖动画帧或鼠标悬停。重复状态通知不能续期，隐藏后迟到通知不能重新弹出。不同错误重新计时；开始下一轮后旧计时器失效。

自动退出只隐藏窗口，不清空控制器保留的正文，不删除历史或录音，不自动复制、发送或重试。历史保存失败时，未落盘正文仍保留在控制器中，不应将提示退出描述为保存成功。

原生复验：运行 `python3 scripts/build-development.py`，给独立 Dev 可执行文件同时设置 `VOICE_INPUT_SEND_PREVIEW_ACCEPTANCE` 和 `VOICE_INPUT_ERROR_ACCEPTANCE` 为本地证据目录。专用驱动重放失败状态并使用真实原生窗口、UI 调度及计时器；`results.json` 核对两种样式的到期隐藏、重复刷新、迟到刷新及下一轮保护。该验收不访问麦克风或调用收费识别。故障清单及构建输出保存于 `artifacts/error-dismissal/`。
