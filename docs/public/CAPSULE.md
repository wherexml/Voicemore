# 听写胶囊

默认靛蓝胶囊的关闭按钮初始隐藏。鼠标进入胶囊及其左侧关闭区域后显示；移出后保留 500 毫秒，再用 200 毫秒动画收回。新一轮听写不得沿用上一轮的悬停状态。原生窗口按当前屏幕鼠标位置判定悬停，并定期刷新，包含启用“减少动态效果”和结果提示静止时。

录音胶囊不显示右侧“结束并写入”对号，使用已配置的触发键结束录音。胶囊不显示说明浮层；鼠标悬停关闭按钮时，只在按钮上方显示 `Esc`。窗口为提示预留顶部空间，胶囊底部位置不变。

键盘导航聚焦关闭按钮时保留关闭入口。开始写入文字后不提供取消。

胶囊在显示期间跟随当前操作屏幕：鼠标跨屏时切换到鼠标所在屏幕；鼠标未跨屏而前台窗口切换或移动时，跟随该窗口所在屏幕。每 200 毫秒检查一次，静音、静止结果和“减少动态效果”下同样生效。始终保持屏幕底部居中及已有底部间距，展开预览不改变胶囊底部位置。窗口跨 macOS 桌面空间及全屏空间显示，保持浮层层级，不激活应用、不抢输入焦点。隐藏后停止跟随，下一轮重新初始化。

## 原生验收

1. 鼠标停在屏幕上方，开始听写：关闭按钮不可见。
2. 移到胶囊：关闭按钮出现；移到关闭按钮的途中不应消失。
3. 移开，等待至少 800 毫秒：关闭按钮不可见。
4. 鼠标在关闭区域结束上一轮，再移到屏幕上方开始下一轮：关闭按钮仍应隐藏。
5. 悬停关闭按钮：上方只显示 `Esc`，不显示“取消”，不出现下方注释；录音时右侧无对号。关闭按钮显示时点击：取消听写且不写入文字。
6. 开启系统“减少动态效果”，重复以上步骤；转写结束的静止提示也须正确响应移入和移出。
7. 用键盘导航聚焦按钮，核对可见性；写入阶段不出现关闭按钮。

8. 双屏开始听写，鼠标跨屏：胶囊在约 200 毫秒内跟随；两种胶囊样式、展开预览、静音和静止结果分别复验。
9. 鼠标保持不动，用键盘切换到另一屏的应用，或切换同应用的窗口：胶囊跟随前台窗口；在目标输入框继续打字，焦点不被抢走。
10. 听写期间切换桌面空间、进入和退出其他应用全屏：胶囊持续可见且位于应用窗口上方；取消后不得再次出现。
11. 显示期间拔掉外接屏、调整 Dock 位置：胶囊仍在有效屏幕底部；连续取消并重启听写不出现旧位置回跳。

保存每次验收使用的构建信息、截图与实测结果到本地 `artifacts/`。渲染器截图不能代替原生窗口鼠标事件验收。
