# 基础格式与数字

基础格式为确定性后处理，不增加模型请求。`textStyle.arabicNumbers` 默认开启，设置 → 文字与粘贴 → 文字整理 → 基础格式中的“数字使用阿拉伯数字”可关闭。旧设置缺字段默认启用，显式关闭持久化；不自动修改旧历史文字。

## 数字规则

| 输入 | 输出 |
| --- | --- |
| 二零二六年十月十六日 | 2026年10月16日 |
| 二零二六、二千零二十六年 | 2026、2026年 |
| 十五个、两个人、第十二个 | 15个、2个人、第12个 |
| 十二点五元、负三点五度 | 12.5元、-3.5度 |
| 百分之十二点五 | 12.5% |
| 下午三点十五分、三点五分钟 | 下午3点15分、3.5分钟 |
| 十五万元、三点五亿元 | 15万元、3.5亿元 |
| 编号零零七 | 编号007 |
| 一个过程、一条建议、一份报告 | 一个过程、一条建议、一份报告 |
| 做一次测试、再试一遍、第一回 | 做一次测试、再试一遍、第一回 |

支持明确的逐位数字、十百千位值、常用日期/数量单位、序号、数值范围、小数和百分数。末尾万亿量级保留，不做无依据的扩写；复杂万亿混合位值和中文缩略数量保守保留。它不是完整的中文语义解析器或所有数词的逆文本规范化引擎。

“一起、万一、十分感谢、一点问题、三心二意”等普通表达保留；“一百二元、一万二元、一块五”等歧义简称不猜测为 120/12000/1.5。“下午一点”可转为“下午1点”，无时间线索的“一点问题”保留。星期、姓名/机构名不能仅凭汉字断言数值，未覆盖的形式保留。

“一”后接“个/项/項/条/條/份/张/張/件/套/台/次/遍/回”（含繁体“個”）保留中文（含“第一次”“一次性”），用于自然单数对象及行动表达；只/每等限定仍保留，其他次数如“三次”仍转为“3次”。显式输入的“1次”不反向替换。整理模型按语境把普通叙述中的“1个/1条/1次/第1次”等恢复为自然中文，保留真实数量和只/每等限制；金额、日期、时间、计量、编号和数量对比维持清楚的数值表达。基础格式不反向改写显式阿拉伯数字，不推断或删除数量。

沿用基础格式的代码、指定引号及 HTTP(S) URL 保护范围，不修改保护片段。原有阿拉伯数字和前导零保持不变，重复应用不继续改变结果。模型已识别错的数字不在这里猜测纠正。

## 数据流

总开关开启：ASR 原文 → 已确认词典纠正 → 基础格式（含数字）→ 文字整理 → 再应用基础格式。关闭时直接交付 ASR 原文。

实时定稿与历史重新转写共享 `Controller.formatTranscript`；历史重新整理也应用相同格式。原始转写仍保存，历史新版本保留 BasedOn，规则命中记录“阿拉伯数字”。整理关闭时数字规则仍生效。partial 预览不在此处改写，数字在定稿/重新转写时规范化。

## 可重复验收

编码前在本地冻结数字/普通词语/引用/歧义/配置持久化失败样例，保存为 `artifacts/numeric-style/failure-cases.json`。运行：

```sh
go run ./cmd/number-acceptance -cases artifacts/numeric-style/failure-cases.json -out artifacts/numeric-style/report.json
```

真实音频验收使用已启动的本地 ASR 五位端口，通过 `-asr http://127.0.0.1:48132` 指定实际服务。运行器从 benchmark-100 选取数字录音，用生产 `session.Controller.Retranscribe` → 格式化 → 历史落盘 → 重读验证，不修改用户历史。可通过 `-history-ids` 提供本机包含年份的真实录音 ID，仅复制到临时历史进行重转写。录音及 ID 不入库。

JSON 保留输入、预期、实际、命中规则、原始 ASR 与新版本；确认旧配置缺字段默认启用、关闭持久化、重复转换幂等。该验收不替代麦克风实时触发、原生开关点击和目标应用粘贴；原生回归另记录实际安装包签名、开关状态与目标文字。

## 总开关联动（2026-10-18）

原生设置 → 文字与粘贴顶部的默认整理文字总开关控制基础格式五项及润色规则；关闭后禁用并保留配置，普通 ASR 直接交付原文，不执行客户端词典、基础格式及独立模型整理。组合云服务的原文选择、计费及自定义规则边界见[整理模块规格](../../internal/cleanup/README.md#原生文字整理总开关2026-10-18)。

sub2api 使用同一组开关和润色规则，格式在云端结算前执行；关闭项目不反向撤销 ASR 本身的 ITN/DDC。服务端协议及原生验收见[云端文字设置](../../internal/cloudasr/README.md#sub2api-文字设置2026-10-18)。
