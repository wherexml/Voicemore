# 自动发送与标准选择器

## 实现前验收边界

先列出可能失败的路径，验收使用真实 macOS 输入窗口，不以模拟按键调用成功替代目标结果。

- 新增应用应继承全局规则；修改全局后，继承项同步生效，独立覆盖不被重置。
- 总开关关闭、应用不发送、空文本、取消、剪贴板回退不得触发发送。
- 最终实际输入应用决定规则，不能使用录音起始应用身份。
- 粘贴尚未消费时不得抢先回车；等待中切应用、切窗口或输入框应跳过发送。
- 每段最终结果只发送一次；不自动重试发送。远程粘贴不继承本机自动发送。
- Enter、Command+Enter、Control+Enter 的修饰键不得粘连。
- 发送清空输入框不得形成修改学习样本，原文仍保留在历史。
- 下拉选项的分组、图标、选中勾、禁用、键盘选择与关闭后焦点一致。
- 设置写入与重启恢复、已有设置兼容、浅色和深色布局需验收。

## 产品行为

文字与粘贴依次为基础格式、自动发送、远程桌面。默认关闭自动发送，只写入原输入框；开启后所有应用默认 Enter；单应用可选跟随所有应用、不发送、Enter、Command+Enter、Control+Enter。新增应用默认跟随，不复制全局值。添加列表来自当前运行中的桌面应用，展示系统图标与名称，按 Bundle ID 去重。

本功能触发目标应用的发送快捷键，不验证服务器送达。用户需将快捷键设为目标应用实际使用的组合。本机全局规则也适用于浏览器与编辑器；远程桌面匹配的粘贴流程不触发自动发送。

## 验收

运行 `scripts/verify-input.sh` 进行原生输入回归；自动发送验收在同一原生窗口夹具中记录输入值与真实键盘事件。截图、日志与 JSON 结果保存在本地 `artifacts/auto-send-native/`，不入库。

## 原生实现

- 配置为 `autoSend.enabled/default/apps`，按最终 Bundle ID 匹配。Store 深拷贝应用列表；启动时只做一次初始预设身份解析，优先 Bundle ID、其次唯一真实应用名称，运行应用按 Bundle ID 去重。
- `macos.Insert` 完成最终粘贴后等待剪贴板恢复窗口；期间持续检查焦点、窗口、取消和剪贴板所有权。可读的输入框须包含待输入正文；不可读编辑器使用原有粘贴能力验证及稳定焦点，不能声称完成文本回读。
- 目标窗口或元素未知、发生切换、正文读取未确认、取消时跳过发送。发送不重试，不向录音起始应用强制切焦点。
- 配置过的远程客户端不继承本机发送规则，包括关闭的远程配置和未匹配窗口。
- 发送启用的这次输入不启动修改学习，避免发送清空被识别为用户编辑。历史保留正文和 `sendShortcut` 或 `sendSkipped`，展示“已触发发送快捷键”，不表示送达。
- `select.go` 的 `standardSelect` 统一模型与自动发送的按钮和弹层。参数为稳定值、文案、分组、可选图标内容、宽度、禁用态和选择回调；支持方向键、Home/End、Enter/Space、Escape 与外部点击关闭。图标由系统应用身份获取；所有应用使用 24×24、1.5px 描边的四圆角方块 SVG。

本地执行：`go build . ./internal/... ./cmd/...`，再运行 `scripts/verify-input.sh`。仓库 artifacts 含历史源码，不能将 `go build ./...` 当作有效源码范围。

自动发送专项可用 `VOICE_INPUT_ACCEPTANCE_AUTO_SEND_ONLY=1 scripts/verify-input.sh` 单独复验，缩短占用前台的时间。前台被其他操作切走会中止；已经完成的用例仍保存 JSON，不记作完整通过。

## 延迟发送实现前失败路径（2026-10-16）

- 默认 2 秒；显式立即发送须保留，旧配置缺省升级为 2 秒。
- 倒计时仅在成功本地粘贴后出现；取消仅取消发送，不撤销正文。
- Escape、叉号、点击编辑与倒计时到期竞争时只能完成一次，取消后不得补发。
- 编辑浮层固定深色；点击编辑不能改变原有位置；按实际换行自适应 1–5 行，超出滚动。
- 编辑时不得覆盖外部输入框中已被用户或应用改动的内容；不可写的目标须保留可复制的编辑文本，不能声称已同步。
- 切换目标、退出、下一次听写必须结束旧倒计时；不重复发送。
- 远程桌面统一控件尺寸和选择组件，已有规则、窗口过滤与等待值不得丢失。

## 延迟、取消与编辑

- `autoSend.delayMs` 缺省为 2000；选项为立即、1、2、3、5 秒，显式 0 不被默认值覆盖。配置克隆保留独立值。
- 成功本地粘贴并恢复剪贴板后开始倒计时；发送前仍检查目标、正文和取消。倒计时内焦点或目标内容变化会取消，不重试。
- 自动发送仅显示倒计时胶囊，不自动显示正文。菜单栏或文字与粘贴设置中的“查看最近文字”主动打开编辑浮层，同时取消本次待发送；Escape、圆环内叉号或外部点击关闭浮层并取消待发送。已粘贴正文和历史保留，成功写回的编辑更新原记录。下一次听写关闭旧浮层。
- 浮层固定 `#1B1B1B` 深色、`#FAFAFA` 正文；无标题、状态说明或嵌套输入框。正文按实际换行适配 1–5 行，超过五行内部细滚动；取消后保留胶囊占位，点击编辑不向下跳。
- 编辑只替换原目标中唯一匹配的本次正文；写回前比较完整快照，保留原有前后文。目标不支持 AX 写入或已被改动时，不覆盖目标，显示复制修改入口。编辑不会恢复自动发送。
- 远程桌面的快捷键、同步等待和新增客户端复用 `standardSelect`；右侧控件统一 220×40，移除列独立 52，窗口过滤规则保持原值。

### 延迟专项复验

先运行 `VOICE_INPUT_ACCEPTANCE_AUTO_SEND_ONLY=1 scripts/verify-input.sh`。21 项覆盖全局与继承、发送组合、远程排除、取消与焦点变化、2 秒默认延迟/立即、编辑写回和冲突。证据保存到本地 `artifacts/current-input/results.json`。

浮层交互使用已签名原生应用和同一原生夹具：以 `VOICE_INPUT_SEND_PREVIEW_ACCEPTANCE=<绝对证据目录>` 启动 Voicemore，在该目录写 `preview-command`。`start` 使用真实 2 秒路径；`start-slow` 仅将验收等待延长为 30 秒便于观察；`focus` 聚焦倒计时以验收叉号/Escape；`inspect` 取消倒计时并聚焦浮层供编辑验收；`close` 清理。驱动仅接受 Bundle ID 为 `dev.steve.voice-input.acceptance-fixture` 的目标，不向聊天应用发送。`preview-state.json` 记录高度、位置及编辑同步，`preview-result.json` 记录最终发送结果。验收副本可并行启动且不注册全局录音热键，正常启动不启用驱动。

## 听写 mock 的标准选择器

`mock/auto-send.html` 中听写设置及首页概览的触发键、麦克风均复用 `mock/components/select.js` 与 `select.css` 的 `VMSelect`；保留自动麦克风的空字符串值、自定义快捷键和断开的设备选项，通过原有设置处理函数保存。复验：切换触发键与麦克风后刷新，重新进入听写确认选项保留；方向键展开、Escape 关闭并恢复焦点。此约定描述 mock，不代表原生客户端已同步。

## 听写原生标准选择器

听写设置的触发键和麦克风复用 `select.go` 的 `standardSelect`。按钮高 40，触发键宽 170、麦克风宽 340；配色跟随应用外观。麦克风以 UID 为稳定值，自动选项保留空字符串；自定义触发键和断开的已选设备继续保留。触发键变更沿用热键重新绑定逻辑。

上下方向键可从按钮展开；菜单内方向键移动、Home/End 到首尾、Enter/Space 确认，Escape 取消。确认和 Escape 关闭后焦点回到原按钮，外部点击可关闭菜单。

原生复验步骤：设置 → 听写，切换右 Option 与真实麦克风；退出并重新打开客户端确认保留；恢复原设置，再检查方向键、Home、Space、Escape、外部点击，以及浅色/深色菜单。2026-10-16 本机实测通过，步骤和截图位于本地 `artifacts/dictation-select-native/`。设备拔插、同名物理设备与自定义快捷键未做硬件专项验收；本次不涉及语音识别质量回归。

### 浮层视觉还原约束

外部点击在 ShowInactive 阶段也通过局部/全局鼠标监听处理，不吞掉点击。编辑态低频核对原输入框，关闭时移除监听并使旧回调失效。历史在听写结果产生时已经创建；浮层关闭不取消或删除历史记录。圆环叉号和 Escape 均关闭整个浮层，点击正文才保留编辑态。

窗口主题背景必须透明：MyGo 的 `SetTheme` 会重写 root 背景，禁止用深色主题背景填充整张窗口；深色只画在 360 DIP 宽、16 DIP 圆角的正文卡片上。正文为 14 DIP 常规字重、24 DIP 固定行高，1–5 行卡片高度为 58–154 DIP。卡片四周留出透明阴影空间；取消后的胶囊占位透明，不可呈现黑色矩形。保留卡片阴影、焦点紫色细边、胶囊靛蓝渐变和 Esc 键帽。验收必须将原生截图与 HTML mock 对照，不能把纯色窗口截图当作透明背景通过。

## V12 默认输入与主动编辑（2026-10-16）

- 新配置默认 `autoSend.enabled=false`，已保存的开关值不强制覆盖。关闭时正常粘贴，不等待发送计时，不弹正文浮层。
- 开启并选择延迟时只显示 40 DIP 倒计时胶囊；立即发送不显示倒计时。目标内容变化立即关闭胶囊并取消，不留下空白窗口。
- 菜单栏和文字与粘贴设置提供“查看最近文字”。仅主动打开时显示深色正文卡片；已有的五行自适应与冲突保护保留。
- 最近输入独立持有目标引用，关闭浮层不丢失结果；原目标支持写回且快照未改变时同步编辑并更新原历史记录。重启后从历史读取最近已输入正文，支持查看与复制修改，不盲目写入新焦点。
- 原生复验：驱动 `input-only` 应只粘贴、发送计数为零、浮层不可见；`start-slow` 应只有倒计时；`inspect` 主动打开正文；Escape/叉号取消后不补发；`start` 到期仅触发一次。证据目录 `artifacts/input-first-native/`。

## V14 原生连续胶囊（2026-10-16，覆盖旧浮层流程）

听写、转录、整理、写入和自动发送倒计时复用 `overlay.win`，不再创建第二个发送窗口。倒计时继承写入时窗口边界与底部留白，期间不跟随显示器切换；40 DIP 胶囊保留渐变、Esc 键帽和圆环叉号。没有正文浮层或最近文字缓存。

Escape、叉号、外部点击、目标焦点或正文变化均取消发送并收起胶囊，保留已经输入的文字。到期仅触发一次配置的发送键；取消或到期后抑制重复完成提示，下次听写正常重置。失败提示仍可显示。默认仅输入，保存过的自动发送配置不被覆盖。

原生复验使用前述专用夹具，`flow` 依次注入准备、聆听、转录、整理和写入状态，再执行真实粘贴与 2 秒自动发送；`flow-slow` 将等待延长为 30 秒以便交互验收。`start`、`input-only`、`focus`、`close` 仍可用；已移除 `inspect`。`timeline.jsonl` 记录窗口句柄、可见性、边界与胶囊底部坐标，用来断言同窗和位置连续；夹具 `state` 记录输入文本和发送次数。阶段注入不代表麦克风或 ASR 质量验收。本地证据保存于 `artifacts/capsule-native/`。

## 首页复用标准选择器（2026-10-17）

`standardSelect` 允许首页提供紧凑触发按钮及面板宽高；设置页默认按钮和面板尺寸不变。选项支持独立组选中、禁用与管理操作，选中行提供可访问 checked 状态，禁用项跳过键盘导航。首页的触发键/方式、模型、麦克风及日期范围行为和原生验收见[首页标准选择器](HOME-HISTORY.md#首页标准选择器2026-10-17)。
