# 首页、历史记录与设置分类

## V3 首页与历史

原生布局以已确认的 `mock/home-v3.html` 和 `mock/history-v3.html` 为基准；演示数据不进入客户端。

首页去掉标题占位和大型设置卡片，顶部使用听写、快捷键与触发方式、识别模型、整理模型、麦克风按钮。开始听写仍延迟三秒，便于回到目标输入框；配置复用设置页保存逻辑。输入趋势与应用分布移到首页，趋势可选近 7/14/30 天；时间从左到右 0–23，日期从新到旧并在右侧悬浮显示。应用按写入字符显示百分比和细横条。下方为最近 12 条记录，支持搜索、应用和小时筛选、显示全部。

历史页保留日期范围与四项数字统计（写入字符、语音输入次数、录音时长、写入率），取消重复图表。保留浅灰边框搜索、结果筛选和分页。录音统计只到分钟；结果横条悬浮显示数量及百分比、点击筛选。

两页使用同一个记录组件。单击正文一次展开完整正文、原文、声纹播放器、录音时长、历史模型、四阶段耗时及重新整理/复制原文。正文与详情同宽、同一容器；外侧仅复制与删除，无再次插入和独立详情按钮。播放按钮为统一的 30×28 圆角 SVG 控件。声纹从实际 PCM16 录音异步计算，支持播放、暂停与跳转；缺失录音明确提示。切换页面、展开其他记录或筛选隐藏当前记录时停止播放。重新整理后的最新版本直接显示，原始写入快照与统计不变。

新录音保存可选 `asrModel` 字段；旧记录不回填当前模型，缺失信息显示横线。未发生阶段显示横线，整理失败明确标记。

私密应用的听写不创建记录、不保存录音，也不计入统计；已有记录不受列表变化影响，见[私密应用](PRIVATE-APPS.md)。

## CSV 导出

历史右上角导出弹窗默认最近 30 个自然日，可通过日历弹层选择或输入起止日期（YYYY-MM-DD），结束日期包含当天。无效范围或空结果在弹窗内提示。通过系统保存对话框选择文件位置。

导出所选日期内全部记录，不受页面搜索、筛选、分页影响。仅四列：本地时间、使用的应用、原文、整理后的结果；不含 UTC 列。UTF-8 BOM、CSV 引号转义及 CRLF 保证中文、逗号和多行兼容；公式前缀做转义。录音文件不导出。

## 设置窗口尺寸与窗口按钮

设置窗口每次启动应用后首次打开为居中的 820×680 DIP，最小为 680×460 DIP；不恢复旧 `prefs` 窗口保存的尺寸、最大化或全屏状态。同一次运行中仍可拖动边缘调整大小，关闭再打开保留当前尺寸和页面草稿。

左上角关闭按钮可用，最小化与全屏/缩放按钮保留系统灰色禁用状态；禁止设置窗口进入全屏。保留窗口背景拖动、分类切换、内容滚动和正常关闭行为。主窗口的尺寸记忆独立保留。

原生验收：保留旧 `prefs` 为最大化/全屏的窗口状态文件，启动新构建并打开设置，确认仍为 820×680 DIP 且全屏按钮灰色禁用；逐一切换六个分类并滚动，检查布局；点击灰色按钮不改变窗口尺寸。拖动边缘后关闭再打开检查尺寸与草稿，退出并重启后再次确认默认尺寸。截图、AX 状态、窗口边界与复验步骤保存到本地 `artifacts/settings-window/`。

## 应用身份与图标

原生捕获目标时保存 `targetApp` 与可选的 `targetBundleID`；旧历史格式可继续读取，不重写旧数据。图标优先由 Bundle ID 经 NSWorkspace 解析；旧记录使用唯一的已安装应用名称，其次唯一的运行中应用名称。辅助进程同名时优先顶层应用 Bundle；同名歧义、卸载或缺失图标保留文字与通用图标，不猜网站或远端应用身份。

成功写入后，`targetApp` 与 `targetBundleID` 必须一起更新为实际写入目标；录音开始后切换应用时，不能混用起始应用的 ID 和最终应用的名称。目标无 Bundle ID 时清空旧 ID。未写入、失败和取消仍保留原捕获身份。验收时分别检查同应用写入与跨应用写入后的持久化字段及历史图标。

图标只在本机缓存，不上传，不包含 Dock 的角标与进度层。新旧记录名称可唯一映射到同一已保存 Bundle ID 时，统计合并；有多个身份时保持区分。首页、历史记录与应用分布共用 20px 系统图标、13px 应用名称。

## V2 原生历史统计（V3 沿用的数据口径）

历史与词典不绘制顶部标题栏，也不保留其 52px 占位。历史从日期范围开始，默认近 7 天，可选今天、近 30 天、全部。顶部四项为写入字符、语音输入次数、录音时长、写入率。录音时长只到分钟；不足一分钟明确显示，不显示秒。写入率无记录时为横线。

统计基于范围内全部真实记录，不受分页、搜索、应用、小时或结果筛选影响。字符仅计成功写入的 `InsertedText`，逐 Unicode 码点去掉空白；后续修订不改变历史写入快照。范围按本机日历日到当前时刻计算。应用百分比以成功写入字符为分母；写入率和结果分段以录音次数为分母。切换范围清除其他筛选。

V3 首页输入趋势与应用分布同为 195px 高，超出内容内部滚动。趋势左边缘与标题对齐，24 个小时列从 0 到 23 左→右排列，日期从新到旧上→下排列。单元格 16px 高，列间距 2px，行间距 3px；无写入为中性底色，未来小时不可选。M/D 日期在右侧保留宽度，悬浮整个趋势面板或键盘焦点进入后显示，不挤动图表。悬浮/聚焦查看完整日期、小时与字符，点击同一格可切换筛选；方向键与 Home/End 对应相邻时段。

应用行展示图标、名称、字符、百分比与独立细横条，可点击筛选。写入率下方结果横条按已写入、未写入、失败、取消的次数分段，悬浮显示数量/百分比，点击筛选。筛选可组合，芯片可单独移除或统一清除；记录详情、播放、复制、重新整理与删除沿用数据层逻辑。首页打开指定记录时切换到全部范围并清除筛选。窗口小于 840px 时，概览改两列；首页窗口小于 650px 时两图上下排列。英文、繁中、简中使用同一布局。

代码入口：`history_stats.go`（聚合与图表）、`history.go`（筛选与详情）、`app_identity.go` 与 `internal/macos/appicon_darwin.go`（本机图标）。词典对应 [词典规格](DICTIONARY.md#v2-原生词典页面)。

## 窗口拖动与滚动条

首页、历史、词典及设置窗口的非交互背景可拖动窗口，顶部留白不再仅限左侧导航栏；主窗口底部保留 16 DIP 的固定拖动区域，长列表滚动到底仍可使用。按钮、输入框、可选文本和滚动条优先处理自身操作。双击背景沿用系统标题栏行为。

各页面滚动条统一为 3 DIP，浅色主题黑色 16% 不透明度，深色主题白色 20% 不透明度；系统增强对比度时保留高对比颜色。保持框架的悬停显示与按内容比例计算滑块长度。

首页最近听写列表的滚动容器距窗口右边缘 8 DIP，容器内右侧再留 20 DIP，供滚动条独立显示与拖动。记录内容、复制/删除按钮与上方搜索框继续在距窗口右边缘 28 DIP 处对齐；不得让滚动条覆盖按钮的点击区域。该间距在收起、展开详情、搜索结果及最小窗口下保持一致，顶部工具栏、图表和筛选栏保持原有宽度。

原生验收：依次打开首页、历史、词典、设置，拖动顶部留白及底部空白，确认窗口位移；操作搜索、导航、导出和滚动条，确认不会误拖窗口；历史/词典长列表滚动后再次检查顶部和固定底部拖动。浅色和深色检查细滚动条，增强对比度检查可见性。保留实际窗口位置及截图到本地 artifacts。

首页间距回归：在有超过一屏记录时悬停记录，检查复制和删除按钮与滚动条分离；滚轮及拖动滑块都能到达“显示全部”，展开记录与搜索后仍右侧对齐。缩至 760×520 DIP 再复验并保留截图和操作记录；删除操作仅允许使用可丢弃记录。
