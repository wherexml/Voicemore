如何使用

不用換視窗，也不用拷貝貼上。

  1. 把游標放在要寫的地方

    郵件、文件、聊天框。Voicemore 待在選單列，不打斷你正在做的事。

  2. 按下快速鍵，開口說

    預設是 Fn，可以換成別的鍵。按一次切換或按住說話，兩種方式任選。

  3. 文字寫入目前的輸入框

    螢幕上的懸浮條顯示錄音和轉錄進度，結束後文字出現在游標所在的位置。

功能

只做語音輸入這一件事，把它做完整。

本機語音模型

內建管理 Qwen3-ASR-1.7B-8bit，在 App 裡下載、部署、啟動。不需要另外安裝推論工具。

雲端辨識

也可以接入阿里雲或火山引擎，使用你自己的服務商帳號和憑證。

選用的文字整理

連接本機或相容的雲端語言模型，把口語整理成書面表達。預設關閉，需要時再開。

歷史與重播

查看每一次轉錄，修改結果，重聽儲存下來的錄音。

個人詞典

熱詞和修正規則讓專有名詞寫對。從你的修改中產生的建議，要你確認後才生效。

原生介面

Dock 與選單列入口，簡體中文、繁體中文和英文介面，App 內一鍵更新。

隱私與資料

聲音去了哪裡，說得清清楚楚。

你選擇哪種辨識方式，決定了音訊會不會離開這台 Mac。

本機辨識
音訊只傳送到本機迴環位址 127.0.0.1:48132 上的推論程序。模型部署完成後可離線使用。
雲端辨識
選擇後，音訊傳送到你設定的服務商。開啟雲端文字整理時，轉錄文字傳送到你設定的介面。
資料存放
設定、歷史、錄音、詞典、模型和加密憑證都儲存在本機的 ~/Library/Application Support/Voice Input/。
錄音保留
預設儲存錄音，保留 30 天，可在設定中調整。

API 憑證使用本機 AES-GCM 加密儲存，密鑰同樣存於本機並使用嚴格的檔案權限。這能避免明文暴露，但不能抵禦以同一 macOS 使用者身分執行的軟體。

常見問題

安裝之前，你可能想知道。

Voicemore 支援哪些 Mac？

需要 Apple Silicon（M 系列）晶片及 macOS 26.2 或以上版本。目前的安裝檔不支援 Intel Mac。最低系統版本由內建的 MLX 執行庫決定。

第一次打開被系統攔截怎麼辦？

目前的預覽版使用開發簽名，尚未完成 Developer ID 簽名和 Apple 公證。確認下載來源後，可在「系統設定 → 隱私權與安全性」中使用「強制打開」為這一個 App 放行。不要全域關閉 Gatekeeper。

一定要連網才能使用嗎？

安裝檔包含推論執行環境，不包含模型權重。第一次部署本機模型需要連網下載約 2.47 GB 模型檔案，並解壓縮約 0.65 GB 執行環境。完成後本機辨識可離線使用。雲端辨識和雲端文字整理需要保持連網。

需要授予哪些系統權限？

麥克風、輔助使用和輸入監控，都在「系統設定 → 隱私權與安全性」中授予。授予鍵盤相關權限後需要重新啟動 App。

按 Fn 時系統跳出了表情符號或切換了輸入法？

在系統鍵盤設定中把「按下 🌐 鍵時」改成「不執行任何動作」，或在 Voicemore 的設定裡換用其他快速鍵。

在所有 App 裡都能寫入文字嗎？

寫入效果受目標 App 和系統權限影響。已驗證在 TextEdit 中聽寫；部分編輯器和受保護的輸入框仍可能有相容性差異。遇到問題歡迎在 GitHub 上回報。

之後怎樣更新？

從 0.3.0 起，App 會在啟動後及執行期間每小時檢查新版本，可在 App 內一鍵下載、驗證 Ed25519 簽名、安裝並重新啟動。設定、模型、歷史及憑證均保留。App 需要安裝在「應用程式」檔案夾中。
