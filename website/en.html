How it works

No window switching. No copy and paste.

  1. Put the cursor where you want to write

    An email, a document, a chat box. Voicemore sits in the menu bar and stays out of your way.

  2. Press the shortcut and speak

    Fn by default, or another key you choose. Press once to toggle, or hold to talk.

  3. The text goes into the current field

    A floating bar shows recording and transcription progress, then the text appears at your cursor.

Features

One job, dictation, done thoroughly.

Local speech model

Qwen3-ASR-1.7B-8bit is managed inside the app: download, deploy and start it there. No separate inference tool to install.

Cloud recognition

Or connect Alibaba Cloud or Volcengine with your own provider account and credentials.

Optional text cleanup

Connect a local or compatible cloud language model to turn speech into tidy writing. Off by default.

History and playback

Review every transcript, edit the result, and listen to the saved recording.

Personal dictionary

Hotwords and correction rules get names right. Suggestions drawn from your edits apply only after you confirm them.

Native interface

Dock and menu-bar access, an interface in English, Simplified Chinese and Traditional Chinese, and one-click updates in the app.

Privacy and data

Where your voice goes, stated plainly.

The recognition mode you choose decides whether audio leaves this Mac.

Local recognition
Audio is sent only to the inference process at the loopback address 127.0.0.1:48132. Once the model is deployed it works offline.
Cloud recognition
When selected, audio is sent to the provider you configured. With cloud text cleanup on, the transcript is sent to the endpoint you configured.
Where data lives
Settings, history, recordings, dictionary, models and encrypted credentials are stored on this Mac in ~/Library/Application Support/Voice Input/.
Recording retention
Recordings are saved by default and kept for 30 days. You can change this in Settings.

API credentials are stored encrypted with AES-GCM on this Mac; the key is also stored locally with strict file permissions. This avoids plain-text exposure but does not protect against software running as the same macOS user.

FAQ

Before you install.

Which Macs does Voicemore support?

An Apple Silicon (M-series) chip and macOS 26.2 or later. The current package does not support Intel Macs. The minimum system version is set by the bundled MLX runtime.

What if macOS blocks the app the first time?

The current preview is development-signed and has not completed Developer ID signing or Apple notarization. After confirming where you downloaded it, use “Open Anyway” in System Settings → Privacy & Security to allow this one app. Do not turn Gatekeeper off globally.

Do I need an internet connection?

The package includes the inference runtime but not the model weights. Deploying the local model the first time downloads about 2.47 GB of model files and unpacks about 0.65 GB of runtime. After that, local recognition works offline. Cloud recognition and cloud text cleanup need a connection.

Which system permissions are needed?

Microphone, Accessibility and Input Monitoring, all granted in System Settings → Privacy & Security. Restart the app after granting the keyboard-related permissions.

Pressing Fn opens the emoji picker or switches input source?

In the system Keyboard settings, set “Press 🌐 key to” to “Do Nothing”, or choose another shortcut in Voicemore’s settings.

Does text insertion work in every app?

It depends on the target app and system permissions. Dictation into TextEdit has been verified; some editors and protected fields may still behave differently. Reports on GitHub are welcome.

How do updates work?

Since 0.3.0 the app checks for a new version after launch and hourly while running. One click downloads it, verifies its Ed25519 signature, installs it and restarts. Settings, models, history and credentials are kept. The app must be installed in the Applications folder.
