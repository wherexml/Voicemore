怎样使用

不用换窗口，也不用复制粘贴。

  1. 把光标放在要写的地方

    邮件、文档、聊天框。Voicemore 待在菜单栏，不打断你正在做的事。

  2. 按下快捷键，开口说

    默认是 Fn，可以换成别的键。按一次切换或按住说话，两种方式任选。

  3. 文字写入当前输入框

    屏幕上的悬浮条显示录音和转录进度，结束后文字出现在光标所在的位置。

功能

只做语音输入这一件事，把它做完整。

本地语音模型

内置管理 Qwen3-ASR-1.7B-8bit，在应用里下载、部署、启动。不需要另外安装推理工具。

云端识别

也可以接入阿里云或火山引擎，使用你自己的服务商账号和凭证。

可选的文字整理

连接本地或兼容的云端语言模型，把口语整理成书面表达。默认关闭，需要时再开。

历史与回放

查看每一次转录，修改结果，回听保存下来的录音。

个人词典

热词和纠错规则让专有名词写对。从你的修改中生成的建议，要你确认后才生效。

原生界面

Dock 与菜单栏入口，简体中文、繁体中文和英文界面，应用内一键更新。

隐私与数据

声音去了哪里，说得清清楚楚。

你选择哪种识别方式，决定了音频会不会离开这台 Mac。

本地识别
音频只发送到本机回环地址 127.0.0.1:48132 上的推理进程。模型部署完成后可离线使用。
云端识别
选择后，音频发送到你配置的服务商。开启云端文字整理时，转录文字发送到你配置的接口。
数据存放
设置、历史、录音、词典、模型和加密凭证都保存在本机的 ~/Library/Application Support/Voice Input/。
录音保留
默认保存录音，保留 30 天，可在设置中调整。

API 凭证使用本机 AES-GCM 加密存储，密钥同样存于本机并使用严格的文件权限。这能避免明文暴露，但不能抵御以同一 macOS 用户身份运行的软件。

常见问题

安装之前，你可能想知道。

Voicemore 支持哪些 Mac？

需要 Apple Silicon（M 系列）芯片及 macOS 26.2 或更新系统。当前安装包不支持 Intel Mac。最低系统版本由内置的 MLX 运行库决定。

首次打开被系统拦截怎么办？

当前预览版使用开发签名，尚未完成 Developer ID 签名和 Apple 公证。确认下载来源后，可在“系统设置 → 隐私与安全性”中使用“仍要打开”为这一个应用放行。不要全局关闭 Gatekeeper。

必须联网才能使用吗？

安装包包含推理运行环境，不包含模型权重。首次部署本地模型需要联网下载约 2.47 GB 模型文件，并解压约 0.65 GB 运行环境。完成后本地识别可离线使用。云端识别和云端文字整理需要保持联网。

需要授予哪些系统权限？

麦克风、辅助功能和输入监控，都在“系统设置 → 隐私与安全性”中授予。授予键盘相关权限后需要重启应用。

按 Fn 时系统弹出了表情或切换了输入法？

在系统键盘设置中把“按下 🌐 键时”改成“不执行任何操作”，或在 Voicemore 的设置里换用其他快捷键。

在所有应用里都能写入文字吗？

写入效果受目标应用和系统权限影响。已验证在 TextEdit 中听写；部分编辑器和受保护的输入框仍可能存在兼容性差异。遇到问题欢迎在 GitHub 上反馈。

之后怎样更新？

从 0.3.0 起，应用会在启动后及运行期间每小时检查新版本，可在应用内一键下载、验证 Ed25519 签名、安装并重启。设置、模型、历史及凭证均保留。应用需要安装在“应用程序”文件夹中。
